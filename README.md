# Physics of Data | Complex Networks Projects

This repository contains the simulations and analysis developed for the final exam of the **Physics of Complex Networks** course in the **Physics of Data** master’s program at the University of Padova (AY 2025/26).

## Repository Layout
* `code/task_15/`: Code for the Bak–Tang–Wiesenfeld sandpile simulation.
* `code/task_44/`: Data pipeline and processing scripts for the Social Connectedness Index.
* `data/`: Final exported deliverables and simulation profiles.

---

## Projects

### Self-Organized Criticality (#15)
Theoretical characterization and numerical analysis of the Bak–Tang–Wiesenfeld sandpile model for self-organized criticality on interdependent networks. 
The analysis focuses on the critical properties of the system, avalanche distributions, and risk minimization across varying coupling parameters.
* **Score:** 0.6

### Social Connectedness Index (#44)
Data ingestion and structural taxonomy of national social networks using GADM1 and NUTS3 boundary datasets.
The project involves building geographic networks, producing mandatory node and edge lists, and evaluating network densification scaling laws across different country-level structures.
* **Score:** 1.0
